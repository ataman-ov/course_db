# Контрольные вопросы

## 1. Дайте определение проекции

Проекция — это операция реляционной алгебры, которая позволяет выбрать определённые столбцы из таблицы.

Проекция уменьшает количество атрибутов в результате запроса.

### Пример

```sql
SELECT product_code, output_volume
FROM product;
```

---

## 2. Опишите понятие селекции

Селекция — это операция реляционной алгебры, предназначенная для выбора строк таблицы, удовлетворяющих заданному условию.

### Пример

```sql
SELECT *
FROM production
WHERE output_volume > 1000;
```

---

## 3. Через какую операцию реляционной алгебры можно выразить пересечение?

Пересечение можно выразить через операцию разности.

Формула:

```text
A ∩ B = A − (A − B)
```

---

## 4. Какие разновидности операции «соединение» вы знаете?

Основные разновидности соединений:

- INNER JOIN — внутреннее соединение;
- LEFT JOIN — левое внешнее соединение;
- RIGHT JOIN — правое внешнее соединение;
- FULL JOIN — полное внешнее соединение;
- CROSS JOIN — перекрестное соединение;
- SELF JOIN — соединение таблицы самой с собой.

---

## 5. Какие типичные запросы реализуются с помощью операции деления? Что такое операция деления?

### Операция деления

Операция деления используется для поиска объектов, связанных со всеми элементами другого множества.

### Типичные запросы

С помощью операции деления можно определить:

- сотрудников, работающих над всеми проектами;
- студентов, сдавших все экзамены;
- изделия, присутствующие во всех категориях.

---

## 6. Что такое SQL, назначение языка SQL?

SQL (Structured Query Language) — язык структурированных запросов.

SQL предназначен для:

- создания баз данных;
- управления таблицами;
- добавления данных;
- изменения данных;
- удаления данных;
- выполнения запросов;
- управления доступом к данным.

---

## 7. Назначение команды SELECT

Команда SELECT используется для выборки данных из таблиц базы данных.

### Пример

```sql
SELECT *
FROM product;
```

---

## 8. Как применить агрегатную функцию?

Агрегатные функции применяются для вычислений над набором строк.

Основные агрегатные функции:

- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()

### Пример

```sql
SELECT AVG(output_volume)
FROM production;
```

---

## 9. Чем отличаются WHERE от HAVING?

| WHERE | HAVING |
|---|---|
| Фильтрует строки до группировки | Фильтрует группы после GROUP BY |
| Используется без агрегатных функций | Используется с агрегатными функциями |
| Выполняется раньше GROUP BY | Выполняется после GROUP BY |

### Пример WHERE

```sql
SELECT *
FROM production
WHERE output_volume > 500;
```

### Пример HAVING

```sql
SELECT group_id, AVG(output_volume)
FROM production
GROUP BY group_id
HAVING AVG(output_volume) > 500;
```

---

## 10. Чем отличаются использование DISTINCT от группировки?

| DISTINCT | GROUP BY |
|---|---|
| Удаляет дублирующиеся строки | Группирует данные |
| Используется для уникальных значений | Используется для агрегатных вычислений |
| Не выполняет вычисления | Часто используется с агрегатными функциями |

### Пример DISTINCT

```sql
SELECT DISTINCT group_id
FROM product;
```

### Пример GROUP BY

```sql
SELECT group_id, COUNT(*)
FROM product
GROUP BY group_id;
```
