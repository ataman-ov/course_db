# Ответы на вопросы

## 1. Что такое внешнее и внутреннее объединение, чем отличаются?

### Внутреннее объединение (INNER JOIN)

Внутреннее объединение возвращает только те строки, для которых существуют совпадающие значения в обеих таблицах.

### Пример INNER JOIN

```sql
SELECT *
FROM product p
INNER JOIN production pr
ON p.product_id = pr.product_id;
```

---

### Внешнее объединение (OUTER JOIN)

Внешнее объединение возвращает совпадающие строки, а также строки без совпадений из одной или обеих таблиц.

Виды внешнего объединения:

- LEFT JOIN
- RIGHT JOIN
- FULL JOIN

---

### Отличия INNER JOIN и OUTER JOIN

| INNER JOIN | OUTER JOIN |
|---|---|
| Возвращает только совпадающие строки | Возвращает совпадающие и несовпадающие строки |
| Строки без совпадений исключаются | Строки без совпадений сохраняются |
| Используется для связанных данных | Используется для полного анализа данных |

---

## 2. Что такое левое, правое и полное объединение?

### LEFT JOIN (левое объединение)

Возвращает все строки из левой таблицы и совпадающие строки из правой таблицы.

Если совпадения отсутствуют, выводится `NULL`.

### Пример LEFT JOIN

```sql
SELECT *
FROM product p
LEFT JOIN production pr
ON p.product_id = pr.product_id;
```

---

### RIGHT JOIN (правое объединение)

Возвращает все строки из правой таблицы и совпадающие строки из левой таблицы.

Если совпадения отсутствуют, выводится `NULL`.

### Пример RIGHT JOIN

```sql
SELECT *
FROM product p
RIGHT JOIN production pr
ON p.product_id = pr.product_id;
```

---

### FULL JOIN (полное объединение)

Возвращает все строки из обеих таблиц.

Если совпадения отсутствуют, вместо данных выводится `NULL`.

### Пример FULL JOIN

```sql
SELECT *
FROM product p
FULL JOIN production pr
ON p.product_id = pr.product_id;
```

---

## 3. Что такое перекрестный запрос?

Перекрестный запрос — это запрос, который преобразует строки в столбцы для удобного анализа данных.

Перекрестные запросы применяются для:

- построения отчетов;
- анализа статистики;
- создания сводных таблиц.

### Пример перекрестного запроса

| Группа изделий | 2022 | 2023 | 2024 |
|---|---|---|---|
| Детали | 1500 | 0 | 0 |
| Узлы | 0 | 800 | 0 |
| Механизмы | 0 | 0 | 450 |

---

## 4. Для чего в стандарт SQL2 были введены объединения?

Объединения были введены в стандарт SQL2 для:

- упрощения работы с несколькими таблицами;
- повышения читаемости SQL-запросов;
- получения связанных данных из разных таблиц;
- поддержки сложных аналитических запросов;
- более удобной обработки информации.

Использование JOIN делает SQL-запросы более понятными и удобными для сопровождения.
